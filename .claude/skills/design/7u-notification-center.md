### 7u. Notification Center
Access: bell icon in header, click opens panel
Panel: slide-in from right, width:380px
Header: "Notifications" + "Tout marquer lu" link

Tabs: Toutes | Non lues | Critiques

Each notification:
- Icon left: type-specific colored circle
- Title: Inter 14px w500
- Subtitle: Inter 13px #5A8BAC
- Timestamp: relative "Il y a 3h"
- Unread: bg:#F0F7FB, left border 3px accent
- Read: bg:white no border
- Click: navigates to relevant screen

Types:
- Échéance: calendar icon amber
  - "G50 Avril à soumettre dans 3 jours"
- Anomalie: shield icon red
  - "Doublon facture détecté"
- Agent IA: sparkle icon green
  - "G50 Mars prêt à vérifier"
- Système: info icon blue
  - "Import CSV terminé: 45 factures"

Empty state:
- Icon: BellOff 32px #B8D4E8
- "Aucune notification"

Settings link bottom: → Settings > Notifications
Badge on bell: count unread, red dot, max "9+"
