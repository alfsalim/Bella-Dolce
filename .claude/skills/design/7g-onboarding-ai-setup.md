### 7z. Onboarding AI Setup
Access: first login after registration
Replaces basic onboarding from 7g
Fullscreen wizard, no sidebar

Step 1 - Bienvenue:
- "Bienvenue sur Jibaya" H1 centered
- "Configurons votre espace en 3 minutes"
- Animated Jibaya logo
- "Commencer" primary button

Step 2 - Entreprise:
- Same fields as 7g step 1
- AI: NIF input → auto-fetches company info
- Auto-fills: raison sociale, adresse, régime
- User confirms or corrects

Step 3 - Import données:
- "Comment voulez-vous démarrer?"
- Card options:
  - "Importer mes factures" → upload zone
  - "Connecter ma banque" → bank auth
  - "Partir de zéro" → skip
- Multi-select: can pick
- Multi-select: can pick both import + bank

Step 4 - Assistant IA:
- "Rencontrez votre assistant"
- Chat demo: agent introduces itself
- Agent: "Je suis Jibaya, votre assistant fiscal"
- Agent: "Je peux préparer vos G50, détecter les erreurs..."
- User tries: type or click suggestion pill
- Shows agent capability live

Step 5 - Récapitulatif:
- Summary card of everything configured
- Entreprise: name + NIF
- Données: X factures importées
- Banque: connectée ou non
- "Tout est prêt!" green checkmark
- "Accéder à mon tableau de bord" primary button
- Confetti animation on click
